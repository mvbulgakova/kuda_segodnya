# Ночь перед КР

Кооперативная 3D-игра адаптации первокурсников Института математики и информатики МПГУ.

Живой документ. Правки в первую очередь сюда, а не в код.

---

## Логлайн

Ночь с 19 на 20 октября 2025 года. Через восемь часов — первая внутрисеместровая аттестация. Команда первокурсников заперта в корпусе на Гаврикова 7-9. Электронные замки защёлкнуло из-за аварии в районе, связь с одногруппниками — только через мессенджер. За ночь надо найти конспекты, разгадать головоломки корпуса и утром сдать первую в жизни настоящую КР.

## На что это работает

- Игрок за один сеанс запоминает: корпус Гаврикова, ключевые аудитории, кто такой семинарист, что такое куратор, где деканат
- Игроки внутри команды знакомятся между собой (главный кооп-крючок — необходимость проговаривать вслух то, что видишь)
- Мягкая тренировка «педагогического рефлекса» — параллельная ветка «объясни школьнику»
- Атмосфера факультета: собирательные преподы-архетипы, реальные тематические дни адаптационного модуля, реальные аудитории

## Границы MVP (30-60 минут)

- 2-4 игрока (min 2)
- Один корпус (Гаврикова 7-9) + пасхалка с намёком на Малую Пироговскую 1
- 3-4 задания-акта + финальная КР
- Роль-специализации: 4 архетипа
- Мультиплеер: ENet, host+клиенты по IP или через VPS
- Плейсхолдер-графика вместо фото на старте, фото подставляются позже

## Роли

Игрок на старте выбирает специализацию. Каждый умеет всё на минимум, специализация даёт +скорость и +подсказки в своём типе задач и уникальную «активную» способность.

| Роль | Тип задач | Активка | Кого напоминает |
|---|---|---|---|
| **Аналитик** | Пределы, ε-δ, производные, интегралы | Пересчитать сложную задачу за половину времени 1 раз за ночь | препод матана (Матвеев/Эйсымонт-стайл) |
| **Алгебраист** | Матрицы, определители, СЛАУ, преобразования | Разложить сложную формулу на шаги для всей команды | препод алгебры (Ширшова/Михайлова-стайл) |
| **Геометр** | Векторы, планиметрия, стереометрия, построения | Показать чертёж-подсказку, видимый всем игрокам | препод геометрии (Атанасян/Никифорова-стайл) |
| **Староста** | Задач сам не решает, но… | Уболтать NPC-препода отдать конспект без задания; синхронизировать команду | лид группы, будущий учитель |

**Педагогический твист роли «Староста»:** это единственная роль без прокачки задач. Её сила — в коммуникации: она эффективнее говорит с NPC-преподами, координирует таймер, и получает бонус-очки в педагогической мини-игре «объясни школьнику» (см. ниже). Тонко подсвечивает педагогическую специфику МПГУ.

## Акты (≈50 минут суммарно)

Слоганы актов взяты из тематических дней реального адаптационного модуля МПГУ 2025 — это часть узнаваемости.

### Акт 0. «День знаний» — пролог (3 мин)
Катсцены: короткие флешбеки из первых двух недель сентября. 1 сентября — знакомство со структурой ИМИ у ауд. 405. 3 сентября — «Учимся учиться» у Чуйковой (собирательной). 6 сентября — встреча с куратором. Заканчивается кадром «19 октября, воскресенье, вечер». Свет вырубается.

### Акт 1. «Учиться, учиться и учиться» — Разведка (8 мин)
Каждый игрок появляется в разной части корпуса. Ищет NPC-подсказки:
- **Вахтёр** у входа — знает, где были старшекурсники недавно
- **Уборщица** — видела кто-то что-то забыл в ауд. 306
- **Аспирант в лабе 302** — не спит, кодит, обменивается инфой на кофе
- **Стенд расписания** у деканата — читаемая подсказка о том, у кого спросить конспект

Цель акта: каждый игрок нашёл минимум одну зацепку и знает, куда идти во втором акте. Игроки общаются через игровой чат (текст) и голосом.

### Акт 2. «Погружение в профессию» — Тайники (12 мин)
Собираешь листки конспектов старшекурсников, спрятанные по корпусу:
- Ауд. 405 (большая лекционная) — под кафедрой
- Ауд. 306 (математика) — в шкафу
- Ауд. 302/303 (компьютерные) — в системнике
- Ауд. 207 — под доской
- Ауд. 410 — в тумбочке

Каждый листок — часть темы (матан / алгебра / геометрия / информатика для профилей с ПИМ). Специализация помогает распознать раздел с одного взгляда: игрок без спеца видит «какие-то формулы», спец видит «это про монотонность функции».

**Мини-игра «объясни школьнику» (первое включение):** случайно во время акта приходит «звонок» от NPC-школьника — младший брат/подшефный, которому надо сдать контрольную завтра. Тема совпадает с найденным листком. Игрок пишет объяснение в поле (свободный текст) → LLM оценивает: понял / уточняющий вопрос / не понял. За понимание — +1 педагогики (баф на диалоги с NPC-преподами в акте 4).

### Акт 3. «Гимнастика для мозгов» — Обмен через корпуса (10 мин)
Часть материала — только у второго корпуса (за пределами корпуса Гаврикова, у одногруппника дома). Игроки в игре — реально в одной сцене, но по сюжету «связываются с внешним миром». Обмен: описать словами, что нашёл. Инвентарь непередаваем — только словесно. Здесь и происходит разговор в реальности между игроками, знакомство.

Также в этом акте — головоломка на теорию графов, которую можно решить только вчетвером (каждый видит свою вершину сети замков).

### Акт 4. «Корень учения горек» — Загадка старой аудитории (8 мин)
Кооперативная головоломка. На доске в 305 (закрытая аудитория, куда попадаешь через акт 3) — половина решения задачи. Другая половина — у стенда в вестибюле. Только совместив, откроешь дверь к ауд. 401, где для КР спрятаны билеты старших лет.

**Пасхалка:** одна из подсказок ссылается на «старый корпус на Малой Пироговской, дом 1» — историческое здание МПГУ. Не входит в основной геймплей, но упоминание задаёт масштаб факультета (реально там проходит «Знакомство с историей МПГУ» в адаптационном модуле).

### Акт 5. «В добрый путь, первокурсник» — КР (12 мин)
5 задач. По одной на каждую специализацию + одна командная (например, доказательство с шагами: аналитик оценивает предел, алгебраист преобразует, геометр строит, староста собирает и сдаёт).

Оценка команды = среднее по задачам, с бонусом за педагогические очки (сколько раз объяснили школьнику успешно).

**Финалы:**
- **Отлично:** лектор запомнил группу, катсцена — крутые первые пары в семестре
- **Хорошо:** сдали, но семинарист косится, катсцена в столовой ИМИ
- **Удовл.:** переписывание, катсцена «работа над ошибками»
- **Неуд.:** мем-эндинг с деканом, пересдача

В каждой концовке — короткая карточка с реальным фактом про МПГУ (например, что ИМИ образован в 1872 году, старейший педвуз страны). Тексты — согласовать с деканатом.

## Механики Claude (LLM) в игре

Три места, где нужен API Anthropic (модель `claude-haiku-4-5-20251001` — быстрая и дешёвая):

1. **NPC-школьник в педагогической мини-игре.** Игрок пишет объяснение темы → Claude в роли школьника отвечает «понял / не понял / уточнение» с коротким комментарием. Оценка идёт в педагогические очки.
2. **NPC-старшекурсник «Артём»** (опциональная фича) — свободный чат-помощник в игре, отвечает на любые вопросы про МПГУ, но с подложенной базой знаний (структура ИМИ, аудитории, куда идти за справкой).
3. **Генератор задач по матану/алгебре/геометрии** для реиграбельности — каждый прогон КР слегка разный.

Ключ API кладётся в `.env`, не коммитится. Клиент → серверу игры → серверу Anthropic. Прямых вызовов из клиента нет (защита ключа).

## Пост-MVP (к сессии)

- 12 актов кампании по тематическим дням адаптационного модуля
- Второй корпус (Краснопрудная 14) — открывается после MVP
- Реальные 360°-панорамы, потом photogrammetry/Gaussian Splatting из видео
- Персонализация: игрок вводит группу → игра подтягивает реальное расписание, преподов, зачётные даты
- Голосовой чат встроенный
- Оффлайн-режим «команда сидит в столовой, играет в игре, потом делает квест по корпусу в реале» — печатные карточки-подсказки

## Что делает пользователь, что делает Claude

**Пользователь:**
- Открывает проект в Godot 4 Editor (Windows/Mac/Linux)
- Импортирует фото/видео корпусов (когда снимет)
- Тестирует
- Разворачивает сервер (docker-compose с ENet-сервером)
- Согласует использование реальных названий/фактов с деканатом

**Claude (в этой сессии и следующих):**
- Пишет GDScript, .tscn сцены, project.godot
- Пишет серверный LLM-мост (Python FastAPI) для NPC-школьника
- Пишет README, docker-compose, .env.example
- Генерирует задачи для КР
- Обновляет дизайн-док по мере правок
