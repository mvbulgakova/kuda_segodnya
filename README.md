# Ночь перед КР

Кооперативная 3D-игра адаптации первокурсников Института математики и информатики МПГУ. Godot 4, ENet-мультиплеер, LLM-мост на Python для педагогической мини-игры.

Полное описание сюжета, ролей, актов и NPC — в [`GAME_DESIGN.md`](GAME_DESIGN.md).

## Что уже есть

- Скелет Godot 4 проекта: главное меню, лобби, одна 3D-сцена (коридор Гаврикова с двумя тайниками), FPS-контроллер с мультиплеером через ENet
- Autoload-ы: `GameState` (прогресс, роли, конспекты, педагогика), `NetworkManager` (host/join по IP), `LLMBridge` (HTTP-клиент)
- Педагогическая мини-игра «объясни школьнику» — Godot UI + Python-сервер, вызывающий Anthropic API (Claude Haiku 4.5)
- Заготовки под NPC-персонажей (Артём-старшекур, тётя Люба, куратор Валерия) в LLM-мосте

## Чего пока нет

- Настоящих фото/видео корпусов — стоят простые серые боксы (см. «Куда класть медиа»)
- Актов 2-5 (тайники есть только как заготовка, финальной КР ещё нет)
- Экрана выбора конкретной темы для педагогической мини-игры
- Хостинга LLM-моста в интернете и сервера ENet — пока только локально

## Первый запуск

### 1. Godot 4 клиент

1. Скачай [Godot 4.3](https://godotengine.org/download) (Standard, не .NET).
2. Открой этот репозиторий как проект (`Import` → выбрать `project.godot`).
3. Запусти сцену `res://scenes/MainMenu.tscn` (F5 после установки её как главной, либо через кнопку play).

### 2. LLM-мост (Python)

Нужен, только если хочешь тестировать педагогическую мини-игру.

```bash
cd llm_bridge
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# в .env впиши свой ANTHROPIC_API_KEY
uvicorn main:app --reload --port 8000
```

Проверка: `curl http://localhost:8000/health` → `{"status":"ok","model":"claude-haiku-4-5-20251001"}`.

### 3. Двое в кооп локально

- Запусти игру на одном компьютере → «Создать игру» → в лобби смотри «клиенты подключаются по: ...»
- На втором компьютере (в той же сети) → «Присоединиться», вводишь IP хоста
- Хост в лобби жмёт «Начать игру» — оба попадают в коридор Гаврикова, ходят WASD + мышью
- E — взаимодействие с тайниками

Через интернет: нужен либо VPN (Tailscale, Hamachi), либо прокинуть порт `4242/udp` на роутере хоста, либо поднять сервер на VPS.

## Куда класть медиа

- `assets/photos/gavrikova/` — фото корпуса Гаврикова 7-9 (вход, аудитории 204, 207, 301, 302, 303, 304, 306, 307, 401, 402, 404, 405, 410, коридор)
- `assets/photos/krasnoprudnaya/` — фото корпуса Краснопрудная 14 (для пост-MVP)
- `assets/videos/` — видеообзоры для photogrammetry (тяжёлое, в .gitignore, не пушится)
- `docs/schedule/` — учебные планы и расписания в PDF

Форматы: `.jpg` / `.png` для фото, `.mp4` для видео. 360°-панорамы — `.jpg` equirectangular.

Импорт в Godot: положи файл в `assets/photos/gavrikova/aud405.jpg`, в редакторе увидишь его в FileSystem. Дальше используем как текстуру для меша стены/панорамы (это следующая задача).

## Кто что делает

- **Ты (человек):** открываешь Godot Editor, тестируешь визуально, снимаешь фото/видео корпусов, кладёшь их в `assets/`, согласуешь с деканатом использование имён/фактов.
- **Claude (в этой сессии):** пишет и правит GDScript/`.tscn`/Python, генерирует задачи для КР, обновляет `GAME_DESIGN.md`. Открыть редактор Godot из этой сессии не могу.

Если хочешь, чтобы Claude работал прямо на твоей машине (быстрее и не надо гонять через git) — поставь себе [Claude Code CLI](https://claude.com/claude-code) локально: `npm install -g @anthropic-ai/claude-code`, запусти `claude` в корне репо. Все возможности этой сессии + твоя файловая система под рукой.
